# Output Directory

This directory separates review deliverables from the uploaded paper source
and background material.

- `review/` contains the implementation checklist and application-specific
  theory/code cross-reference. Each editable Markdown file is colocated with
  its print-ready PDF counterpart.
- `source/` contains uploaded paper TeX and reference PDFs.

MATLAB runtime files remain in the project root and `tests/`; they are not
copied into this directory.
