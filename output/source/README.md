# Source And Background Material

This directory contains the uploaded non-code paper inputs used for the
paper-to-implementation review.

| File | Description |
| --- | --- |
| `P6_Data_Driven_Co_Design.pdf` | Uploaded 18-page paper; primary theory reference. |
| `P6.tex` | Uploaded TeX source for the paper. |
| `P6_Data_Driven_Co_Design_with_notes.pdf` | Older 16-page annotated paper; retained because it differs from the uploaded version. |

The TeX file references figure, result, bibliography, and style dependencies
that were not included with the upload. No MATLAB implementation files belong
in this directory. The derived review documents and their PDFs are maintained
with the Overleaf/GitHub paper under its
[`Revision/`](https://github.com/shiran27/Data_Driven_Design_ACC2025/tree/main/Revision)
directory.
